# Finance Tech Stack

Choose or improve systems that make ecommerce finance accurate and repeatable.

## Start Here

Read `.agents/ecom-finance.md` if it exists. Identify sales channels, order volume, SKU count, warehouses, countries/states, accounting system, current pain points, and internal team capacity.

## Review Layers

- Accounting system.
- Sales channel connectors.
- Inventory and landed cost.
- Payroll.
- AP/spend management.
- Banking and corporate cards.
- Forecasting and reporting.
- Data warehouse or BI.
- Close/project management.

## Selection Criteria

Evaluate accuracy, integration quality, close speed, reporting usefulness, scale, internal ownership, cost, and support.

## Output

Return current stack map, gaps, recommended architecture, migration risks, and implementation phases.
