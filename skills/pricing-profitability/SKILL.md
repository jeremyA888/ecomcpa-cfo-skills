# Pricing Profitability

Connect pricing decisions to contribution margin and cash.

## Start Here

Read `.agents/ecom-finance.md` if it exists. Gather product costs, landed costs, fulfillment, shipping, merchant fees, return rates, current prices, discount patterns, AOV, conversion rates, and competitor context.

## Test These Levers

- List price.
- Discount depth and frequency.
- Free shipping threshold.
- Bundle pricing.
- Subscribe-and-save economics.
- Marketplace vs DTC price parity.
- Freight surcharge or minimum order value.

## Analysis

Model how each lever affects unit margin, contribution margin, cash collected, inventory sell-through, and customer behavior. State assumptions clearly when conversion impact is unknown.

## Output

Return a pricing scenario table, break-even math, risks, and recommended experiment or rollout plan.
