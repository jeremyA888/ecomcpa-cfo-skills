# Evaluation Data Boundary

Every prompt and assertion in this directory must be synthetic or deidentified. Dates, amounts, entity labels, SKUs, and transaction terms are fabricated test inputs; they are not EcomCPA or client records.

Do not paste credentials, personal data, customer or employee records, account identifiers, raw financials, proprietary company facts, or excerpts from private source systems into an evaluation. Public platform and product names may appear only when they are necessary to test routing or generally available workflow behavior.
